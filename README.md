# 绿循智审 - 再生金属合规校验平台

## 本地运行

首次运行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --index-url https://pypi.org/simple -r requirements.txt
python app.py
```

后续运行只需：

```powershell
.\.venv\Scripts\Activate.ps1
python app.py
```

打开 `http://127.0.0.1:5000`。

## 部署 Render

1. 将项目推送至 GitHub。
2. 在 Render 选择 **New +** → **Blueprint**，连接该仓库。
3. Render 会读取 `render.yaml` 并自动安装、启动。
4. 免费实例休眠后首次访问会有短暂冷启动；比赛正式使用建议本地运行或使用付费实例。

## 如何实验

1. 登录后进入“单据导入”，点击“下载标准 Excel 模板”。模板包含“过磅单”“质检单”“入库单”三个工作表；过磅单包含收款银行卡信息。
2. 也可使用 `Data/再生资源公司收购合规台账模板.xlsx` 作为 59 列合规台账模板，保持第三行字段名不变。
3. 上传模板，系统会真正写入 SQLite 台账，并自动执行 9 项规则。数量规则为“过磅净重 - 质检扣杂数量 = 入库数量”，时间规则为“过磅时间 < 质检时间 < 入库时间 < 付款时间”。
4. 下载模板后，系统会在 `local_templates` 保存本地副本。修改并保存 Excel 后，平台会自动检测并同步；也可以点击“同步本地模板”立即更新。
5. 到“核验中心”查看规则矩阵；会计、出纳和财务负责人都可以对风险业务一键驳回，后台管理员可修改并重新提交单据。
6. 导入后规则全通过的业务会按金额自动进入“待付款”或“待审批”；“核验中心”用于查看规则依据，手动录入或历史待核验业务仍可点击“确认已核验”。
7. 到“付款中心”查看带星号遮罩的虚拟银行卡号，点击小眼睛查看完整号码，再确认付款。
8. 只有规则全部通过且付款全额完成的业务会进入“合规台账”；点开记录可查看驳回历史、原始单据和新版单据。

## 数据管理

本地业务数据保存在项目根目录的 `greenloop.db`。比赛演示如需恢复初始数据，在停止服务后删除这个文件，再重新运行 `python app.py`。
