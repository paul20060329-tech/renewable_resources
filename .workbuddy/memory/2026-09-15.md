# 2026-09-15 工作日志

## 新增访问审计系统（system_admin）

**背景**：网站部署在 Render 免费实例，用户无法查看"谁在何时何地登录"，因 Render 免费版无持久文件系统，且直连 IP 是代理节点。

**方案与实现**：
- 新增 `access_log.py`：访问审计模块，独立于业务库。
  - `client_ip()` 解析 `X-Forwarded-For`（取最左侧公网地址），回退 `X-Real-IP` / `CF-Connecting-IP` / `remote_addr`。
  - 双后端：有 `DATABASE_URL` 走 PostgreSQL（psycopg3，Neon），否则退化本地 SQLite `access_log.db`。
  - 后台线程 + 内存队列批量写入（批 50 条 / 最长 2 秒），连接重试 3 次，队列满丢最旧，保证不拖慢主站。
  - 提供 `query_logs()` / `query_stats()` / `distinct_values()` / `clear_logs()` / `describe_ip()`。
- `app.py`：`import access_log`；`bootstrap()` 初始化业务库 + 审计中间件；`after_request` 中间件记录每次请求；`login()` 增加成功/失败事件（`mark_event`）。
- 新增路由（独立 session 键 `system_admin`，密码 `SYSTEM_ADMIN_PASSWORD`，路径 `SYSTEM_ADMIN_PATH` 默认 `system_admin`）：
  - `GET/POST /system_admin`（登录 + 审计台首页）
  - `POST /system_admin/logout`
  - `GET /system_admin/api/logs`（只读 JSON）
- 新增 `templates/system_admin.html`：深色只读审计台，KPI + 趋势柱状图 + Top IP/用户 + 最近登录 + 筛选分页表格。含 `noindex` 防收录。
- `requirements.txt` 加 `psycopg[binary]`；`render.yaml` 加 `DATABASE_URL`、`SYSTEM_ADMIN_PASSWORD`（均 `sync: false`，Console 手填）、`SYSTEM_ADMIN_PATH`。

**验证结果**（真实连 Neon 自检，9 项全过）：
- Neon 建表、写入、查询、统计均正常；`backend = PostgreSQL (Neon)`。
- XFF 多段（`203.0.113.77, 10.0.0.1`）正确取到公网段。
- 后台错误密钥 401、正确密钥 302、登出后回到登录页；筛选与 API 正常。
